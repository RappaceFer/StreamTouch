## StreamTouch 1.1.1

**Français**
- La grande carte « Course auto » ne s'affiche plus : le double appui sur le joystick de gauche lance toujours la course auto.
- Le bouton du haut du menu rond dit vers quel mode il fait passer : « Mode manette » en tactile, « Mode tactile » en manette.
- Esc envoie seulement Échap : plus de double appui sur Esc pour changer de mode (le double appui sur Clavier le fait toujours).
- Installation par-dessus la 1.1.0 : tes réglages sont gardés.

**English**
- The big "Auto run" card no longer shows: a double tap on the left stick still starts auto run.
- The top button of the round menu names the mode it switches to: "Controller mode" in touch mode, "Touch mode" in controller mode.
- Esc only sends Escape: no more double tap on Esc to switch modes (a double tap on Keyboard still does).
- Installs over 1.1.0: your settings are kept.

The WoW addon is unchanged: **Streaming Touch 2.5.0** (zip attached).
